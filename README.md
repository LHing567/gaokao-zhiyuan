## 安装

```bash
# 1. 确保已安装 Python 3.10+

# 2. 安装依赖
pip install -r requirements.txt
```

依赖只有四个包：`requests`（网络请求）、`numpy` + `scipy`（分数预测）、`openpyxl`（Excel 导出）。

## 快速上手

如果你是第一次用，建议按这个顺序：

1. 先跑 `query.py` 感受一下——查一个学校一个专业
2. 再跑 `school_history.py` 看某个学校所有专业三年变化
3. 最后用 `volunteer.py` 生成冲稳保志愿表

每次查询的数据会自动存到 `score.db`，后面越跑越快。

## 脚本一：query.py — 快速查询

**功能**：查询指定学校、专业、省份、年份的录取分数。

### 使用步骤

1. 用编辑器打开 `query.py`
2. 修改顶部参数：

```python
SCHOOL_NAME = "郑州大学"      # 学校全名，支持模糊匹配（"郑州" 也能匹配到郑州大学）
PROVINCE = "山东"             # 省份全名
WANT_MAJOR = "软件工程"       # 专业关键词，支持模糊匹配
YEAR = 2025                   # 目标年份
```

3. 终端运行：

```bash
python query.py
```

### 输出

- **终端**：打印匹配的专业列表（专业名、最低分、最低位次、选科要求）
- **文件**：同时生成两个文件
  - `output/2025_郑州大学_软件工程_山东.txt`
  - `output/2025_郑州大学_软件工程_山东.xlsx`（Excel 表格，带格式）

### 示例输出

```
省份: 山东 (ID: 37)
学校: 郑州大学 (ID: 62)
从缓存读取: 33 条

============================================================
  郑州大学 | 山东 | 2025年
  匹配「软件工程」的专业: 1 个
============================================================

[1] 软件工程
    最低分: 610    最低位次: 18246    选科要求: 物理、化学(2科必选)
```

### 参数说明

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `SCHOOL_NAME` | 字符串 | 学校名称，支持模糊匹配 | `"郑州大学"` `"清华"` |
| `PROVINCE` | 字符串 | 省份全名 | `"山东"` `"广东"` `"河南"` |
| `WANT_MAJOR` | 字符串 | 专业关键词，模糊匹配 | `"软件工程"` `"计算机"` `"临床医学"` |
| `YEAR` | 整数 | 目标年份 | `2024` `2025` |

## 脚本二：school_history.py — 历年对比

**功能**：查询某个学校在某个省份近三年**全部专业**的录取数据，跨年横向对比，一眼看出分数涨跌。

### 使用步骤

1. 打开 `school_history.py`
2. 修改顶部参数：

```python
SCHOOL_NAME = "山东大学"         # 学校名称
PROVINCE = "山东"                # 省份
YEARS = [2023, 2024, 2025]      # 要对比的年份，年数不限
```

3. 运行：

```bash
python school_history.py
```

### 输出

- **终端**：打印完整的专业对比表格
- **文件**：`output/{学校}_{省份}_{起止年}.txt` + `.xlsx`

### 示例输出

```
山东大学 | 山东  (2023-2025)
77 个专业

专业名称                     | 2023年        | 2024年        | 2025年
                             | 最低分/最低位次 | 最低分/最低位次 | 最低分/最低位次
法学                         | 617 / 14950   | 611 / 16013   | 615 / 15654
计算机科学与技术              | -             | 640 / 5429    | -             
软件工程                     | 615 / 15871   | -             | 610 / 18246
...

选科要求
  法学: 不限
  计算机科学与技术: 物理、化学(2科必选)
  ...
```

### 功能细节

- **专业合并**：同一个专业不同年份名称略有差异时（如"计算机类" vs "计算机类（计算机科学与技术、软件工程）"），自动识别合并到一行
- **名称拼接**：跨年名称不同时用 `/` 拼接展示
- **缺数据标记**：某年没有招生则用 `-` 代替
- **按位次排序**：默认按最新年份的最低位次升序排列
- **选科要求**：表格下方单独列出每个专业的选科要求

### 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `SCHOOL_NAME` | 字符串 | 学校名称，模糊匹配 |
| `PROVINCE` | 字符串 | 省份全名 |
| `YEARS` | 整数列表 | 要对比的年份，`[2023, 2024, 2025]` |

## 脚本三：volunteer.py — 冲稳保排序

**功能**：指定目标院校和专业，按你的排名自动分类**冲 / 稳 / 保**，按山东高考志愿填报格式输出（一校一专业占一行），附带历年分数信息。

### 使用步骤

1. 打开 `volunteer.py`
2. 修改顶部参数：

```python
PROVINCE = "山东"
MY_RANK = 15000                        # ← 改成你的全省排名

WANT_MAJORS = [                        # ← 改成你想报的专业
    "计算机科学与技术",
    "软件工程",
    "电子信息工程",
    "通信工程",
    "人工智能",
    "数据科学与大数据技术",
]
# 如果填 [] 空列表，则输出全部专业

SCHOOLS = [                            # ← 改成你的目标院校
    "山东大学",
    "郑州大学",
    "中国海洋大学",
    "中国石油大学（华东）",
]

PRIMARY_YEAR = 2025                    # ← 主要参考年份（用于冲稳保分类）
HISTORY_YEARS = [2023, 2024, 2025]     # ← 表格中显示哪些年份的数据
CHONG_UP = 10000                       # ← 冲的范围
WEN_RANGE = 5000                       # ← 稳的范围
BAO_DOWN = 15000                       # ← 保的范围
SHOW_ALL = True                        # ← True=显示超出范围的（标记为"其他"）
```

3. 运行：

```bash
python volunteer.py
```

### 输出

- **终端**：分冲/稳/保三段打印
- **文件**：`output/志愿填报_{省份}_{排名}名.txt` + `.xlsx`（Excel 带颜色标记）

### Excel 样式

| 分类 | 颜色 | 含义 |
|------|------|------|
| 🔴 冲 | 红底 | 录取位次比你高，需要冲一冲 |
| 🟡 稳 | 黄底 | 位次差距不大，比较有把握 |
| 🟢 保 | 绿底 | 你的位次明显高于录取线，基本能录取 |
| ⚪ 其他 | 灰底 | 超出分类范围，仅供参考 |

### 冲稳保分类逻辑

以你的排名和该专业往年录取最低位次的差值为依据：

```
差值 = 你的排名 - 专业录取最低位次
```

| 分类 | 条件 | 举例（你排15000名） |
|------|------|---------------------|
| 🔴 冲 | `0 < 差值 ≤ 10000` | 专业录 10000 名 → 差 5000 → 冲 |
| 🟡 稳 | `|差值| ≤ 5000` | 专业录 16000 名 → 差 -1000 → 稳 |
| 🟢 保 | `0 < 录取位次 - 你的排名 ≤ 15000` | 专业录 25000 名 → 差 -10000 → 保 |

> 位次数值越小越好。1 名是全省第一。

### 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `PROVINCE` | 字符串 | 省份全名 |
| `MY_RANK` | 整数 | **你的全省排名**，最重要的参数 |
| `WANT_MAJORS` | 字符串列表 | 目标专业，`[]` = 全部专业 |
| `SCHOOLS` | 字符串列表 | 目标院校 |
| `PRIMARY_YEAR` | 整数 | 用于冲稳保分类的参考年份 |
| `HISTORY_YEARS` | 整数列表 | 表格中显示的历年数据列 |
| `CHONG_UP` | 整数 | 冲的范围上限，默认 10000 |
| `WEN_RANGE` | 整数 | 稳的范围，默认 ±5000 |
| `BAO_DOWN` | 整数 | 保的范围下限，默认 15000 |
| `SHOW_ALL` | 布尔 | 是否显示超出冲稳保范围的结果 |

## 主程序：main.py — 全量搜索

**功能**：按专业关键词**全量搜索**所有院校（或指定院校），适合大范围撒网。支持断点续传。

### 使用步骤

1. 编辑 `config.json`：

```json
{
    "province_id": "山东",
    "rank": 12000,
    "want": "软件工程",
    "year": 2024,
    "output": true,
    "ethnic_minority": false,
    "thread_num": 2,
    "schools": ["山东大学", "郑州大学"]
}
```

2. 运行：

```bash
python main.py
```

### config.json 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `province_id` | 字符串 | 省份名称，如 `"山东"`，程序自动查 ID |
| `rank` | 整数 | 你的排名，筛选 ±3000 名内的专业 |
| `want` | 字符串 | 专业关键词 |
| `year` | 整数 | 目标年份 |
| `output` | 布尔 | `true` = 输出 JSON 文件 |
| `ethnic_minority` | 布尔 | 少数民族专项计划才设 `true` |
| `thread_num` | 整数 | 并发数（暂未启用） |
| `schools` | 数组 | `[]` = 全部院校；`["清华","北大"]` = 只查指定院校 |

### 断点续传

运行中如果中断（网络问题、手动停止），再次运行 `python main.py` 会自动从上次断的地方继续，不会重复查询已处理过的学校。进度保存在 `progress.db`。

## 共享缓存机制

三个查询脚本（`query.py` / `school_history.py` / `volunteer.py`）共用同一个 SQLite 数据库 `score.db`。

```
工作流程：
  查询请求 → 查 score.db 缓存
        ↓ 有 → 直接返回（秒出）
        ↓ 没有 → 调 API 拉取 → 写入 score.db → 返回
                            ↓
              其他脚本下次就能直接用
```

缓存以 `(学校ID, 省份ID, 年份)` 为唯一标识，不同脚本写入不会互相覆盖。数据越攒越多，查询越来越快。

## 常见问题

### Q: 终端输出乱码 / 表格对不齐？

A: 这三个脚本同时输出 `.xlsx` 文件，用 Excel / WPS 打开看，不会有对齐问题。

### Q: 运行报 `1069 访问太过频繁`？

A: API 限流了。等 5-10 分钟再跑。缓存里的数据不受影响，可以直接用。首次查询大量学校时可以分批次跑。

### Q: 找不到某个学校？

A: 学校名需要和 `schoolid.json` 里的名称匹配。可以打开 `schoolid.json` 搜索确认准确名称。

### Q: 某年数据全是 `-`？

A: 可能该学校那年在目标省份没有招生，或者该年的 API 数据还没拉取到缓存。等限流解除后跑一次 `school_history.py` 就能补上。

### Q: 冲稳保范围怎么调？

A: 编辑 `volunteer.py` 顶部的 `CHONG_UP`、`WEN_RANGE`、`BAO_DOWN`。数值越大分类越宽松，结果越多。

## 项目结构

```
score_to_school/
├── query.py                  # 快速单查（单校·单专业·单年）
├── school_history.py         # 历年对比（单校·全专业·多年）
├── volunteer.py              # 冲稳保排序（多校·多专业·山东格式）
├── main.py                   # 全量搜索（全院校·关键词筛选）
├── process.py                # 全量搜索核心逻辑（断点续传）
├── guess.py                  # 线性回归分数预测
├── config.json               # 全量搜索配置
├── schoolid.json             # 全国院校 ID 库（517KB）
├── score.db                  # 共享查询缓存（自动生成）
├── progress.db               # 断点续传进度（自动生成）
├── requirements.txt          # Python 依赖
├── Get_informations/         # API 请求模块
│   ├── Getpage.py            #   分页请求
│   ├── GetScore.py           #   缓存 + 查询
│   ├── Get_school_id.py      #   加载院校列表
│   └── Get_province_id.py    #   省份名 → ID
└── output/                   # 查询结果（TXT + Excel）
```
